usv_vision Jetson nvvidconv 试跑命令清单
========================================

改动记录
--------
1. `gmsl_camera_algo_640.yaml` 已从 CPU 管线切到 `nvvidconv -> BGRx -> videoconvert -> BGR`
2. `gmsl_camera_algo_640.yaml` 的 `fps` 目标已从 `15.0` 调整为 `30.0`
3. 原 CPU 版本已备份为 `gmsl_camera_algo_640_cpu_backup.yaml`
4. 如需回退，可直接用备份配置重新启动


1. 进入工作区并加载环境
----------------------
cd /home/cczh/USV_ROS
source /opt/ros/humble/setup.bash


2. 确认新旧配置都在
------------------
ls /home/cczh/USV_ROS/src/usv_perception/usv_vision/config/gmsl_camera_algo_640.yaml
ls /home/cczh/USV_ROS/src/usv_perception/usv_vision/config/gmsl_camera_algo_640_cpu_backup.yaml


3. 重新编译
----------
cd /home/cczh/USV_ROS
source /opt/ros/humble/setup.bash
colcon build --packages-select usv_interfaces usv_vision
source install/setup.bash


4. 检查 nvvidconv 插件
---------------------
gst-inspect-1.0 nvvidconv
gst-inspect-1.0 videoconvert
gst-inspect-1.0 appsink


5. 先用纯 gst 验证 nvvidconv 640x640 管线
----------------------------------------
gst-launch-1.0 -ev \
  v4l2src device=/dev/video4 ! \
  video/x-raw,format=UYVY,width=1920,height=1536,framerate=30/1 ! \
  nvvidconv ! \
  video/x-raw,format=BGRx,width=640,height=640 ! \
  videoconvert ! video/x-raw,format=BGR ! \
  fpsdisplaysink text-overlay=1 video-sink=fakesink sync=0


6. 启动新的低分辨率算法链
------------------------
cd /home/cczh/USV_ROS
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch usv_vision usv_vision.launch.py \
  namespace:=front_gmsl_algo \
  gmsl_config:=/home/cczh/USV_ROS/src/usv_perception/usv_vision/config/gmsl_camera_algo_640.yaml


7. 检查新算法链输出
------------------
ros2 topic echo /front_gmsl_algo/frame_timing_json --once
ros2 topic hz /front_gmsl_algo/image_raw
ros2 topic bw /front_gmsl_algo/image_raw


8. 启动旧 CPU 备份版本做对照
---------------------------
cd /home/cczh/USV_ROS
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch usv_vision usv_vision.launch.py \
  namespace:=front_gmsl_algo \
  gmsl_config:=/home/cczh/USV_ROS/src/usv_perception/usv_vision/config/gmsl_camera_algo_640_cpu_backup.yaml


9. 检查旧 CPU 备份版本输出
-------------------------
ros2 topic echo /front_gmsl_algo/frame_timing_json --once
ros2 topic hz /front_gmsl_algo/image_raw
ros2 topic bw /front_gmsl_algo/image_raw


10. 保存资源日志
---------------
mkdir -p /home/cczh/USV_ROS/test_logs
tegrastats --interval 1000 --logfile /home/cczh/USV_ROS/test_logs/tegrastats_nvvidconv_try.log


11. 使用自动采集脚本跑新配置
---------------------------
cd /home/cczh/USV_ROS
bash src/usv_perception/usv_vision/scripts/jetson_collect_benchmarks.sh \
  --case-name ros_bgr_640_front_nvvidconv \
  --mode ros \
  --launch-cmd "cd /home/cczh/USV_ROS && source /opt/ros/humble/setup.bash && source install/setup.bash && ros2 launch usv_vision usv_vision.launch.py namespace:=front_gmsl_algo gmsl_config:=/home/cczh/USV_ROS/src/usv_perception/usv_vision/config/gmsl_camera_algo_640.yaml" \
  --topic /front_gmsl_algo/image_raw \
  --duration 20 \
  --startup-wait 6 \
  --pipeline-type ros_bgr_nvvidconv \
  --target-resolution 640x640 \
  --results-dir /home/cczh/USV_ROS/test_logs/benchmarks \
  --notes "front camera ros low resolution nvvidconv"


12. 使用自动采集脚本跑旧 CPU 备份配置
------------------------------------
cd /home/cczh/USV_ROS
bash src/usv_perception/usv_vision/scripts/jetson_collect_benchmarks.sh \

  --mode ros \

  --topic /front_gmsl_algo/image_raw \

  --startup-wait 6 \
  --pipeline-type ros_bgr_cpu_backup \
